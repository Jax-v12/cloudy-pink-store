## Investigasi HTTP 500 katalog

`src/app/api/products/route.ts` menjalankan `prisma.product.findMany()` sebelum `resolveRequestRegion()`. Error database ditangkap `apiError()` menjadi `500 SYSTEM_ERROR`; guard URL pada `src/lib/prisma.ts` juga dapat menghentikan inisialisasi modul. Tidak tersedianya GeoIP sendiri bukan bukti penyebab 500: setelah query berhasil, lokasi tidak terverifikasi seharusnya menghasilkan katalog dengan checkout terblokir.

Reproduksi terisolasi tanpa database: GET katalog menghasilkan `500 SYSTEM_ERROR`; probe koneksi dengan konfigurasi dummy yang sama menghasilkan `PrismaClientInitializationError / P1001`. Ini mengonfirmasi jalur kegagalan koneksi lokal, **bukan penyebab pasti error OpenCode terdahulu**. Konfigurasi aktual/schema remote dan log lama sengaja tidak diperiksa. Tidak ada backend/security bypass yang dibuat.
